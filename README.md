# TPIW (The Path I Want)

เกมจำลองเส้นทางชีวิตภาษาไทย เริ่มตั้งแต่วัยเด็กหรือเลือกช่วงอายุเริ่มต้น แล้วตัดสินใจเรื่องเรียน งาน เงิน ความสัมพันธ์ และการอยู่ร่วมกับคนหลากหลายตัวตน

## วิธีรัน

ต้องมี Node.js รุ่นที่รองรับ `node --test` และ ES modules

```bash
npm install
npm run dev
```

เปิด `http://127.0.0.1:3000/` ในเบราว์เซอร์ เซฟเกมเก็บในอุปกรณ์ที่เล่น สำหรับการทดสอบใช้ `npm test` และ `npm run validate:data`

## ระบบในเกม

- เมืองพิกเซลพร้อมชาวเมืองประจำ อีเวนต์พบปะและบทสนทนาที่การเลือกคำตอบส่งผลต่อความสัมพันธ์
- โทรศัพท์ที่มีฟีด ik, แชต lane, กล้อง, ข่าว และกระเป๋าเงิน
- ระดับความสัมพันธ์ตั้งแต่เพื่อนสนิท คนคุย แฟน หมั้น แต่งงาน ไปจนถึงการเลิกราและความสัมพันธ์ลับ
- อีเวนต์พิเศษตามช่วงอายุ งาน การเรียน สินทรัพย์ หนี้ และการส่งต่อชีวิตให้ทายาท
- ระบบเงินสมจริงสำหรับตัวละครใหม่ หรือเปิดเองในข้อมูลตัวละครของเซฟเก่า ราคาสินค้าและค่าครองชีพเปลี่ยนตามเงินเฟ้อ ตัวเลขเป็นการประมาณสำหรับเกม ไม่ใช่ตัวเลขทางการ
- การสำรวจและเปลี่ยนตัวตนทางเพศ พร้อมผลสะท้อนจากครอบครัว เพื่อน และเมือง
- AI สร้างสถานการณ์ บทสนทนา และคำแนะนำเมื่อกำหนดตัวแปรแวดล้อม หากไม่พร้อม เกมใช้เนื้อหาในเครื่อง

## ตั้งค่า AI (ไม่บังคับ)

กำหนดคีย์ผ่านตัวแปรแวดล้อมของเซิร์ฟเวอร์ ห้ามใส่คีย์ลงในไฟล์ที่เผยแพร่

| ตัวแปร | หน้าที่ |
| --- | --- |
| `PATHUMMA_API_URL` | URL endpoint ของบริการ Pathumma (ค่าเริ่มต้น `https://api.aiforthai.in.th/textqa/completion`) |
| `PATHUMMA_API_KEY` | คีย์ Pathumma |

สำหรับ deploy เป็น Node Web Service ให้ตั้ง build command เป็น `npm install`, start command เป็น `npm run dev` และ `HOST=0.0.0.0` พร้อมใช้ `PORT` จากโฮสต์
