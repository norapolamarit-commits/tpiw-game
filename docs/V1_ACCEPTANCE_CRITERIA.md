# V1 Acceptance Criteria — TPIW

**สถานะเอกสาร:** Phase 5A — Release Acceptance Baseline  
**วันที่:** 2026-11-14  
**Baseline:** `main` @ `c066f79e7f45b62e2ca0e71f210e5fa51927462e`

เกณฑ์ชุดนี้กำหนดว่าเกมต้องทำอะไรได้จึงจะเรียกว่า V1 พร้อมให้ผู้เล่นภายนอกทดลอง ไม่ใช่เพียงมีไฟล์หรือมีปุ่มสำหรับฟีเจอร์นั้น

## 1. New Life & Initialization

- [ ] เริ่มชีวิตใหม่ได้โดยไม่ต้องมี Save เดิม
- [ ] ตั้งค่าตัวละคร/ข้อมูลเริ่มต้นตามตัวเลือกที่ UI รองรับได้
- [ ] สร้างข้อมูลครอบครัว ชนชั้น จังหวัดเกิด และสถานะเริ่มต้นโดยไม่เกิดค่าอ้างอิงที่ไม่มีอยู่ในฐานข้อมูล
- [ ] เริ่มคิว Event ปีแรกได้ และไม่มีหน้าจอว่างหรือการกระทำที่ทำให้เริ่มเล่นต่อไม่ได้
- [ ] Save เริ่มต้นถูกเขียนและโหลดกลับได้

## 2. Turn, Age & Full-life Flow

- [ ] การกดปุ่มหลักทำงานตรงกับ Turn Phase ปัจจุบัน
- [ ] Event Queue แสดง Event ตามลำดับที่กำหนด และการเลือก Choice ทำให้คิวเดินหน้าได้จริง
- [ ] ป้องกันการเลือก Choice ที่ล็อกไว้หรือเลือกซ้ำจนเกิดผลซ้ำ
- [ ] การจบ Event Queue และการเปลี่ยนเข้าสู่ Free Action ทำงานได้
- [ ] การเริ่มปีถัดไปเพิ่มอายุหนึ่งปีและประมวลผลระบบประจำปีตามลำดับ
- [ ] การเล่นต่อเนื่องตั้งแต่แรกเกิดจนถึง Ending ทำได้โดยไม่ต้องแก้ State ด้วยมือหรือเรียกฟังก์ชันจาก Console
- [ ] การเสียชีวิต/จบชีวิตทำให้เข้าสู่ Ending อย่างถูกต้อง ไม่มีการกลับไปเล่นต่อใน State ที่จบแล้ว

## 3. Life Path & Event

- [ ] ผู้เล่นสามารถเลือกหรือกำหนด Life Path ตามแบบที่ออกแบบไว้
- [ ] Life Path ถูกบันทึกใน GameState และคงอยู่หลัง Save/Load
- [ ] Life Path ส่งผลต่อโอกาส/คุณสมบัติของ Event, กิจกรรม หรือเส้นทางความก้าวหน้าอย่างตรวจสอบได้
- [ ] การไม่มี Life Path หรือการเลือกเส้นทางที่ไม่เข้าเงื่อนไขต้องมี fallback ที่ไม่ทำให้ Event Queue ว่าง
- [ ] Event เดิมที่ไม่เกี่ยวกับ Life Path ยังทำงานได้ ไม่ถูกลบหรือถูกแทนที่โดยไม่ตั้งใจ
- [ ] Event ที่มีเงื่อนไขต้องมีทางตรวจสอบได้ว่าเหตุใดจึงเข้า/ไม่เข้าเงื่อนไข

## 4. Meaningful Choices & Narrative

- [ ] Choice แต่ละข้อมีคำอธิบายที่เข้าใจได้และสอดคล้องกับเหตุการณ์
- [ ] Choice สำคัญมีความแตกต่างด้านต้นทุน ความเสี่ยง ความสัมพันธ์ หรือผลระยะยาว
- [ ] แสดงค่าใช้จ่ายและเงื่อนไขที่จำเป็นก่อนยืนยัน
- [ ] ไม่เปิดเผยตัวเลขผลลัพธ์ทุกอย่างล่วงหน้าโดยไม่มีเหตุผลด้านการออกแบบ
- [ ] Choice ไม่ใช่การรับผลบวกแบบไม่มีต้นทุนเป็นส่วนใหญ่
- [ ] จำนวน Choice ปรับตามเนื้อหาได้ ไม่บังคับให้ทุก Event มีจำนวนเท่ากัน
- [ ] ข้อความผลลัพธ์และ Life Feed ตรงกับผลที่ Engine ประมวลผล

## 5. Stats, Traits & Statuses

- [ ] ค่าสถานะถูกจำกัดตามขอบเขตที่กำหนด และไม่เกิด NaN/Infinity
- [ ] Threshold ที่ 0/100 และตัวนับข้ามปีทำงานถูกต้องตามกฎเกม
- [ ] Trait, Tag, Flag และ Status ที่ผู้เล่นมี ส่งผลตามนิยามและไม่ถูกนับซ้ำ
- [ ] การได้/เสีย Flag ไม่ทำให้ข้อมูลซ้ำหรือค้างในหมวดที่ไม่ถูกต้อง
- [ ] การเพิ่มสถานะจาก Event, กิจกรรม และระบบรายปีให้ผลสอดคล้องกัน

## 6. Family, Education & Career

- [ ] ความสัมพันธ์กับ NPC เปลี่ยนได้ตามการกระทำและ Event
- [ ] NPC ที่เสียชีวิตหรือไม่เข้าเงื่อนไขไม่ถูกประมวลผลเป็นบุคคลที่ยังมีชีวิต
- [ ] การเรียน การสมัครงาน การเปลี่ยนอาชีพ และความก้าวหน้าในอาชีพทำงานได้ตามข้อกำหนด
- [ ] เงื่อนไขอายุ คุณสมบัติ ใบอนุญาต และค่าใช้จ่ายของการศึกษา/อาชีพถูกตรวจสอบก่อนดำเนินการ
- [ ] การแต่งงาน บุตร การเลี้ยงดู และความสัมพันธ์ในครอบครัวไม่ทำให้ State เสียรูปแบบ

## 7. Economy, Assets & Investments

- [ ] เงินสด กระปุกออมสิน เงินสนับสนุนจากครอบครัว รายรับ รายจ่าย และ Net Worth คำนวณได้ถูกต้อง
- [ ] รายรับ/รายจ่ายไม่ถูกบันทึกซ้ำจากการเรียก Pipeline หรือ Action ซ้ำ
- [ ] ผู้เล่นไม่สามารถซื้อ/ลงทุน/ชำระเงินเกินทรัพยากรที่อนุญาต เว้นแต่ระบบนั้นออกแบบให้เกิดหนี้
- [ ] หนี้สิน ดอกเบี้ย ผ่อนชำระ การผิดนัด และการแก้ไขเงินสดติดลบส่งผลต่อเนื่องถูกต้อง
- [ ] การลงทุนมีเงื่อนไข ความเสี่ยง และการคำนวณกำไรขาดทุนที่ตรวจสอบได้
- [ ] ฐานะครอบครัวมีผลต่อจุดเริ่มต้น แต่ไม่ทำให้ผู้เล่นมีเงินส่วนตัวโดยอัตโนมัติโดยไม่มีรายการบัญชีรองรับ
- [ ] ทดสอบอย่างน้อย 4 สถานการณ์: ครอบครัวรายได้น้อย, ปานกลาง, มั่งคั่ง และผู้เล่นที่มีรายได้/หนี้สินของตนเอง

## 8. Ending, Inheritance & Next Generation

- [ ] สาเหตุการเสียชีวิตและ Ending Tier ตรงกับเงื่อนไข
- [ ] Final report สรุปข้อมูลชีวิตและรางวัลข้ามชีวิตได้โดยไม่คำนวณซ้ำ
- [ ] การร่างพินัยกรรมและการกำหนดทายาททำงานตามข้อกำหนด
- [ ] การส่งต่อมรดกไม่ทำให้ยอดเงินหรือสินทรัพย์ซ้ำ/หาย
- [ ] เริ่มรุ่นทายาทได้ และ State ของรุ่นใหม่ไม่ปะปนกับ State ของรุ่นก่อน
- [ ] กลับสู่ Lobby ได้โดยไม่ทิ้ง State ของชีวิตก่อนหน้าไว้เป็นเกมที่กำลังเล่น

## 9. Save/Load & Recovery

- [ ] Save/Load เก็บข้อมูลที่จำเป็นต่อการเล่นทั้งหมด รวมถึง Event Queue และ Choice Outcome ที่กำลังรอแสดงผล
- [ ] Reload ระหว่าง Event แล้วกลับมาในตำแหน่งเดิมได้
- [ ] Save ที่มี field เก่าหรือขาด field ที่รองรับได้ถูกเติมค่าอย่างปลอดภัย
- [ ] Save ที่เสียหายหรือเป็น Schema รุ่นใหม่ที่ไม่รองรับไม่ทำให้แอป Crash แบบควบคุมไม่ได้ และไม่เขียนทับข้อมูลเดิมอย่างเงียบ ๆ
- [ ] MetaState ข้ามชีวิตแยกจาก Save ของชีวิตปัจจุบัน
- [ ] ทดสอบการบันทึกและโหลดซ้ำบน Browser/อุปกรณ์จริง ไม่ใช่เฉพาะ Mock localStorage

## 10. UI, Mobile & Audio

- [ ] Lobby, Reborn, Gameplay ทั้งห้าแท็บ และ Ending แสดงผลโดยไม่ Error
- [ ] ปุ่มที่กดไม่ได้ถูก Disable และ Action สำคัญมี Feedback
- [ ] ไม่มีปุ่มสำคัญถูกบังด้วย Safe Area, Bottom Dock, Keyboard หรือ Modal
- [ ] ใช้งานผ่านหน้าจอมือถือแนวตั้งได้ ทั้งการแตะ การเลื่อน และการยืนยัน Modal
- [ ] BGM และ SFX เปิด/ปิดแยกกันได้
- [ ] ระดับเสียง BGM และ SFX ปรับแยกกันได้ และมีระดับ Master ที่เหมาะสมตามข้อกำหนด Audio Phase
- [ ] MP3 SFX และ Synth SFX เล่นได้หลังผู้ใช้ปลดล็อก Audio Context
- [ ] ไม่มีเสียงคลิกซ้ำหรือเสียงซ้อนที่ไม่ตั้งใจ
- [ ] การสลับแท็บ/แอปและกลับมาไม่ทำให้เพลงเล่นซ้ำหลายชุด

## 11. Data, Automated QA & Manual QA

เกณฑ์อัตโนมัติปัจจุบัน:

- [x] `npm test` ผ่านใน CI ล่าสุดบน baseline commit: **111 passed, 0 failed**
- [x] `npm run validate:data` ผ่าน: **20 JSON files, 562 events, 1,191 choices**
- [x] CI workflow มีขั้นตอน Run tests และ Validate game data

- [ ] มีการทดสอบ Full-life run ต่อเนื่องตั้งแต่เริ่มชีวิตจน Ending
- [ ] มี Scenario test ครอบคลุมฐานะเริ่มต้นและเส้นทางชีวิตต่างกัน
- [ ] Manual test บน Android Chrome และ Desktop Chrome ผ่าน
- [ ] ทดสอบ Save/Reload บนเครื่องจริง
- [ ] ตรวจ Console/Network ว่าไม่มี Error ที่ขัดขวางการเล่น
- [ ] ทดลองกับผู้เล่นภายนอกอย่างน้อย 3 คน และจดปัญหาที่พบก่อน Release Candidate

## 12. Release Gate

V1 จะยังไม่ถือว่าเสร็จหากมีข้อใดข้อหนึ่งต่อไปนี้:

1. มี Softlock หรือไม่สามารถเล่นจนถึง Ending
2. Save/Load ทำให้ความคืบหน้าสูญหายหรือสถานะสำคัญย้อนกลับ
3. ระบบเศรษฐกิจ/สถานะมี Exploit ที่ทำให้ระบบหลักไร้ความหมาย
4. Life Path ที่ประกาศไว้ไม่มีผลในเกมจริง
5. มี Error บนอุปกรณ์เป้าหมายที่ขัดขวางการเล่น
6. มีการกล่าวอ้างว่า PWA/Offline พร้อมใช้งานทั้งที่ยังไม่ได้ทดสอบ

**หมายเหตุ:** ผล CI ปัจจุบันเป็นหลักฐานว่า Automated suite และ Data Validation ผ่าน ณ baseline เท่านั้น ไม่ใช่การรับรองว่าการเล่นทั้งชีวิต สมดุลเกม หรือทุกอุปกรณ์ผ่านแล้ว
