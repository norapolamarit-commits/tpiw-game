# ระบบเหตุการณ์สุ่มแบบพลวัต

ส่วนเสริมนี้เชื่อมกับเกม **TPIW (The Path I Want)** โดยใช้คิวเหตุการณ์และระบบผลลัพธ์จากตัวเลือกเดิม

## เริ่มเล่น

ต้องมี Node.js รุ่นที่รองรับ `node --test` และ `fetch` ในตัว

```sh
npm install
npm run dev
```

เปิด `http://127.0.0.1:3000` ในเบราว์เซอร์ เกมเล่นได้โดยไม่ต้องมีคีย์ AI

หากต้องการเปิดการสร้างเหตุการณ์ด้วย AI ให้ตั้ง `OPENAI_API_KEY` ในสภาพแวดล้อมของเซิร์ฟเวอร์ก่อนรัน คีย์ไม่ถูกส่งไปยังเบราว์เซอร์ สามารถตั้ง `OPENAI_EVENT_MODEL` เพื่อเลือกโมเดลที่รองรับ Structured Outputs ได้ การเรียก AI ล้มเหลวจะกลับไปใช้เหตุการณ์ที่เขียนไว้แล้ว

ค่าเริ่มต้นของเซิร์ฟเวอร์รับการเชื่อมต่อเฉพาะเครื่องนี้ หากทดสอบจากอุปกรณ์อื่นในเครือข่าย ให้ตั้ง `HOST=0.0.0.0` โดยพิจารณาความปลอดภัยของเครือข่ายที่ใช้งาน

## ปรับค่าความน่าจะเป็น

แก้ค่าที่ `js/core/event_settings.js`:

- `eventTriggerChance`: โอกาสมีเหตุการณ์สุ่มในปีนั้น
- `maxEventsPerTurn`: จำนวนเหตุการณ์สุ่มสูงสุดต่อปี
- `extraEventChance`: โอกาสได้เหตุการณ์สุ่มใบที่สองหลังมีใบแรก
- `cooldownTurns`: ระยะพักก่อนเหตุการณ์เดิมอาจกลับมา
- `rarityWeights`: น้ำหนักทั่วไป/พิเศษ/หายาก/สำคัญมาก
- `aiGenerationChance`: โอกาสขอเหตุการณ์ AI แยกจากโอกาสเกิดเหตุการณ์และน้ำหนักความหายาก

## เนื้อหาและความต่อเนื่อง

คลังใหม่มีเหตุการณ์ภาษาไทย 158 รายการ และนำเหตุการณ์เดิม 125 รายการมาเข้าระบบสุ่มใหม่ เหตุการณ์ใหม่มี 2 ตัวเลือกพร้อมผลต่างกัน ผ่านระบบค่าสถานะของเกม การเลือกบางข้อสร้าง NPC หรือบันทึกเรื่องราวสำหรับเหตุการณ์หลายปีต่อมา ประวัติและสถานะ RNG อยู่ในเซฟ

เหตุการณ์เกี่ยวกับความหลากหลายทางเพศให้ผู้เล่นพบและรู้จักผู้คนหลายอัตลักษณ์ อัตลักษณ์ไม่ใช่สถานะเสีย และหน้าความสัมพันธ์แสดงข้อมูลดังกล่าวเมื่อ NPC เป็นผู้เปิดเผยเอง

## ตรวจสอบ

```sh
npm test
npm run validate:data
```

การทดสอบ AI จริงต้องมีคีย์ที่ใช้งานได้ การทดสอบอัตโนมัติครอบคลุมการตรวจ JSON/Zod การปฏิเสธผลเกินกติกา ความต่อเนื่อง NPC และการใช้เหตุการณ์ที่เขียนไว้แล้วเมื่อ AI ล้มเหลว
